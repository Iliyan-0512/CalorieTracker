# CalorieTracker

Личен тракер за калории и макроси: мобилно приложение на **.NET MAUI** и **ASP.NET Core Web API**.
Изграден по MVP спецификацията от сравнителния анализ на BitePal, Health4Wealth и MyFitnessPal:
бързо логване, подробен нутриентен анализ и опростен интерфейс. Без реклами и без акаунт, а данните остават на устройството.

## Функции (MVP)

| Приоритет | Функция | Статус |
|---|---|---|
| 1 | Логване на хранене: търсене, баркод (OpenFoodFacts), ръчно добавяне на храна | ✅ |
| 2 | Автоматично изчисляване на калории, белтъчини, въглехидрати, мазнини и фибри | ✅ |
| 3 | Цели: BMR/TDEE (Mifflin-St Jeor), отслабване/поддържане/качване, % макроси, ръчна цел | ✅ |
| 4 | История и диаграми: калории по дни спрямо целта, графика на теглото, статистика | ✅ |
| 5 | Apple Health / Google Fit | ⏳ след MVP |
| 6 | Офлайн: локална SQLite база с 35 основни храни (вкл. сирене, кашкавал, баница…) | ✅ |
| 7 | UI: бутон „+“, секции по хранения, светла/тъмна тема | ✅ |

**Мобилно приложение:**
- **Дневник**: навигация по дни, изядени/цел/остават, прогрес на макросите, хранения (закуска, обяд, вечеря, междинно). Докосване на храна променя количеството, плъзгане наляво я изтрива.
- **Добави храна**: търсене (нечувствително към главни/малки букви, вкл. кирилица), последно използвани, баркод с търсене в OpenFoodFacts и кеширане локално, собствени храни.
- **Прогрес**: 7/30/90 дни, средни калории, дни в целта (±10%), промяна в теглото, графики.
- **Цели**: профил, изчислени BMR/TDEE/цел на живо, разпределение на макросите, избор на тема.

## Архитектура

```
src/
  CalorieTracker.Core   – модели, NutritionCalculator, EF Core (SQLite), услуги, OpenFoodFacts клиент
  CalorieTracker.Api    – ASP.NET Core Minimal API върху Core
  CalorieTracker.Maui   – .NET MAUI приложение (Android, iOS, macOS, Windows), MVVM (CommunityToolkit.Mvvm)
tests/
  CalorieTracker.Tests  – unit тестове за изчисленията + интеграционни тестове за API-то
```

Мобилното приложение и API-то ползват **една и съща** бизнес логика от `Core`. Приложението работи изцяло
офлайн с локална SQLite база. API-то е за бъдеща синхронизация, уеб клиент или ползване от други устройства.

### API endpoints

| Метод | Път | Описание |
|---|---|---|
| GET | `/api/foods?search=` | Търсене в базата храни |
| GET | `/api/foods/{id}` | Храна по id |
| GET | `/api/foods/barcode/{code}` | Търсене по баркод (локално → OpenFoodFacts) |
| GET | `/api/foods/recent` | Последно използвани храни |
| POST | `/api/foods` | Добавяне на собствена храна |
| GET | `/api/meals?date=` | Дневен дневник с обобщени нутриенти и остатък |
| POST | `/api/meals` | Запис на хранене |
| PUT / DELETE | `/api/meals/{id}` | Промяна на количество / изтриване |
| GET / PUT | `/api/profile` | Профил и цели |
| GET | `/api/profile/targets` | Изчислени BMR, TDEE, калории и макроси |
| GET / POST | `/api/weights` | История на теглото / запис |
| GET | `/api/stats?days=7` | Статистика за графики |

Примерни заявки има в [`CalorieTracker.Api.http`](src/CalorieTracker.Api/CalorieTracker.Api.http).

## Стартиране

Изисквания: .NET 11 SDK. За мобилното приложение е нужен и MAUI workload (`dotnet workload install maui`).

```bash
# API (http://localhost:5080, OpenAPI: /openapi/v1.json)
dotnet run --project src/CalorieTracker.Api

# Тестове
dotnet test

# Мобилно приложение – Windows
dotnet build src/CalorieTracker.Maui -f net11.0-windows10.0.19041.0 -t:Run

# Мобилно приложение – Android (емулатор или свързан телефон)
dotnet build src/CalorieTracker.Maui -f net11.0-android -t:Run
```

Може и директно от Visual Studio: отворете `CalorieTracker.slnx` и изберете `CalorieTracker.Maui`.

## Изчисления

- **BMR** (Mifflin-St Jeor): `10·kg + 6.25·cm − 5·години + 5` (мъже) / `− 161` (жени)
- **TDEE** = BMR × коефициент на активност (1.2 / 1.375 / 1.55 / 1.725 / 1.9)
- **Цел**: TDEE − 500 kcal (отслабване), TDEE (поддържане), TDEE + 300 kcal (качване), но не под 1200 kcal
- **Макроси**: белтъчини и въглехидрати 4 kcal/g, мазнини 9 kcal/g
